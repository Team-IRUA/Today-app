T.O.DAY 시연 앱 실행 방법 (Windows)
====================================

[1] 처음 실행하기 (가장 쉬운 방법)
  1. 압축을 풀어 폴더를 바탕화면 등에 둡니다.
  2. 폴더 안의 run_windows.bat 파일을 더블클릭합니다.
  3. 처음에는 필요한 프로그램을 설치하느라 1~3분 걸립니다.
  4. 브라우저에 앱이 자동으로 열립니다. (안 열리면 주소창에 http://localhost:8501 입력)
  5. 끝낼 때는 검은 창(명령 프롬프트)을 닫으면 됩니다.

  ※ "python을 찾을 수 없습니다" 오류가 나면:
     Python 설치 시 "Add python.exe to PATH"를 체크하지 않은 경우입니다.
     오류 화면을 캡처해서 Claude에게 보여 주세요.

[2] 데모 모드 vs AI 모드
  - API 키를 비워 두면 "데모 모드"로, 미리 준비된 예시 결과를 보여줍니다.
  - 왼쪽 사이드바에 Claude API 키를 넣으면 "AI 모드"로, 실제 Claude가 답합니다.
  - 시연 영상은 반드시 AI 모드로 찍어야 "실제로 AI가 판단한다"는 걸 보여줄 수 있어요.

[3] Claude API 키 발급 (Claude 구독과 별개)
  1. https://console.anthropic.com 에 가입합니다. (Claude와 같은 이메일 사용 가능)
  2. 결제 수단을 등록하고 소액 크레딧을 충전합니다. (쓴 만큼만 차감)
  3. API Keys 메뉴에서 새 키를 만들고 복사합니다. (sk-ant-로 시작)
  4. 앱 사이드바의 "Claude API 키" 칸에 붙여 넣습니다.
  ※ 키는 비밀번호와 같습니다. 다른 사람에게 보여 주거나 화면 녹화에 찍히지 않게 하세요.
  ※ 비용을 아끼려면 사이드바에서 "Claude Haiku 5.5 (저렴·빠름)"을 고르세요.

[4] 탭별 사용법
  ⓪ 소개        : 서비스 소개 (영상 폴더에 소개.mp4를 넣으면 재생)
  ① T.O 게시판  : 7개 가상 기업의 T.O를 한눈에 보기 → 카드 자세히 보기
                  아래 '새 T.O 내기'에서 예시 기업을 불러오거나 직접 고민을 써서 새 T.O 만들기
                  (새로 만든 T.O는 게시판·튜터·매칭에 바로 추가됨)
  ② 역량 레이더 : 공고 붙여넣기 → AI 역량 분류·차트 → '사람판단' 칸으로 일치율 계산 → CSV 저장
  ③ AI 튜터     : 이름·전공·목표 T.O를 고르고 '시작' 입력
                  데모 모드에서도 전공 계열과 T.O에 따라 수업 내용이 달라짐 (3턴까지 진행)
  ④ 실습 매칭   : T.O를 고르면 학생 11명 중 적합도 상위 5명 추천 (T.O마다 결과가 달라짐)

  ■ 시연 영상 추천 흐름 (약 2분)
    1) ① 게시판에서 여러 기업 T.O를 훑어보기
    2) '새 T.O 내기'에서 직접 고민을 써서 카드가 생기는 장면
    3) ③ 튜터에서 화학 + 화학소재 A사 → 간호학 + 요양병원 D 로 바꿔 수업이 달라지는 장면
    4) ④ 매칭에서 T.O를 바꾸면 추천 학생이 바뀌는 장면

[5] 파일 설명
  app.py               앱 본체
  sample_postings.txt  예시 채용공고 5건 (가상) → 실제 고용24 공고로 바꿔 쓰세요
  sample_students.csv  예시 학생 11명 (가상 인물)
  기업목록.json        게시판의 가상 기업 7곳
  requirements.txt     필요한 프로그램 목록
  run_windows.bat      더블클릭 실행 파일

[6] 주의
  - 예시 공고와 학생은 가상 데이터입니다. 제출 자료에 쓸 때 "가상"이라고 표시하세요.
  - 실제 공고에서 회사명·연락처 등은 지우고 쓰는 것을 권장합니다.

[7] 앱을 직접 고치는 법
  ■ 메모장으로 쉽게 고칠 수 있는 파일 (추천)
    전공목록.txt         ③ AI 튜터의 전공 선택지. 한 줄에 하나씩 추가·삭제
    역량목록.txt         ② 역량 레이더의 AI 역량 분류 기준
    sample_students.csv  ④ 매칭의 학생 목록 (엑셀로 열어서 고치고 CSV로 저장)
    sample_postings.txt  ② 역량 레이더에 처음 보이는 공고 (공고 사이는 --- 한 줄)
  → 저장한 뒤 브라우저에서 F5(새로고침)를 누르면 바로 반영됩니다.
  → 메모장에서 저장할 때 인코딩은 'UTF-8'로 두세요. (글자가 깨지면 이것 때문이에요)

  ■ app.py 를 고쳐야 하는 것 (조심해서)
    데모 모드에서 보이는 예시 결과는 app.py 안의 DEMO_TO_CARD, DEMO_RADAR,
    DEMO_TUTOR, DEMO_MATCH 부분에 있어요. 따옴표 안의 글자만 바꾸고,
    따옴표·쉼표·괄호는 건드리지 마세요. 앱이 안 열리면 원래 파일로 되돌리면 됩니다.
    고치기 전에 app.py를 복사해 백업해 두세요.

  ■ 데모 모드의 한계
    데모 모드는 미리 적어 둔 예시만 보여줘요. 전공을 바꿔도 튜터 답은 그대로예요.
    전공별로 답이 달라지는 걸 보여주려면 나중에 API 키를 넣으면 됩니다.

  ■ 기업을 추가·수정하려면 (기업목록.json)
    메모장으로 열면 기업마다 { ... } 묶음이 있어요. 기존 묶음 하나를 통째로 복사해서
    마지막 } 뒤에 쉼표(,)를 찍고 붙여 넣은 다음 글자만 바꾸세요.
    쉼표·따옴표·괄호가 하나라도 틀리면 게시판이 비어 보여요. 그럴 땐 백업본으로 되돌리세요.
    추천_전공은 전공목록.txt에 있는 이름과 똑같이 써야 매칭 점수에 반영됩니다.
